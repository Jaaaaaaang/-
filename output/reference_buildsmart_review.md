## 2. 우리 과제에 쓸 수 있는 것 (채택)

### A. 가중합 점수 + 가중치 슬라이더 패턴 → **구역 위험지수 민감도 분석** ★ 즉시 적용
- BuildSmart `supplier_recommendation_page`: MinMax 정규화 5개 지표 × 사용자 조정 가중치(0.4/0.2/0.2/0.15/0.05) → Final_Score, UI에서 가중치를 바꾸면 순위가 즉시 재계산됨
- **우리 적용**: 구역 종합 위험지수(아차 .25·경보 .15·혼재 .15·미조치 .15·재발 .10·RA .10·High .10)가 "팀 가정 가중치"라는 약점을 보완 → 가중치를 무작위로 1,000회 교란해도 **B2·D2가 상위 2위를 유지하는 비율**을 제시하면 우선순위 선정의 강건성을 입증할 수 있음
- 구현: `analysis/04_sensitivity.py` (자체 작성)

### B. "구조화된 예측 결과 → LLM 자연어 설명 + 완화조치" 프롬프트 패턴 → **F3 TBM 특별지시 자동 초안**
- `utils.generate_ai_explanation()`: 입력값·예측등급·지연일수를 템플릿에 채워 GPT에게 "쉬운 말로 핵심 요인과 완화전략 설명" 요청
- **우리 적용**: Pre-Clash Gate가 생성한 익일 충돌 체크리스트(빨강/노랑 항목)를 동일 패턴으로 TBM `Special_Instruction` 문구 초안으로 변환 → 안전팀 검수 후 배포. 단, BuildSmart는 검수 단계가 없음 → 우리는 **"사람 검수 필수"**를 명시(환각 위험)
- 도메인 제한 system prompt(건설 외 질문 거절) 방식은 AI활용·검증기록의 "프롬프트 설계 의도" 작성에 참고

### C. 자동 PDF 리포트(FPDF) + 일일 스케줄러(schedule) → **주간 KPI 리포트 자동화**
- `risk_report_generator.py`: 예측 결과 → 막대차트 → FPDF 요약/상세 PDF / `automation_tasks.py`: `schedule.every().day.at("10:00")`
- **우리 적용**: 90일 로드맵의 "주간 KPI 리포트"를 매주 토요일 16:00 자동 생성(10개 KPI 표 + fig 갱신). 외부비 0원 구성 가능 → 예산 산출근거 보강. 한글 폰트(NanumGothic) 임베딩 필요

### D. YOLO 탐지 성능 수치 → **CCTV 집계 데이터의 한계 근거** (§9 한계·추가 데이터)
- 공개 PPE 데이터셋 YOLOv8n 100 epoch: **mAP50 0.81, Recall 0.73** / 저장소 자체 학습(11 epoch): mAP50 0.54
- 클래스: Person, machinery, vehicle, Safety Cone, Hardhat/NO-Hardhat, Vest/NO-Vest, Mask/NO-Mask → 우리 `04_camera_object_log`의 People/Forklift/Truck/Excavator_Count와 개념적으로 대응
- **우리 적용**: "AI CCTV 슬롯 집계값은 Recall 0.7~0.8 수준의 탐지 누락을 전제해야 하므로 Proximity_Alert·People_Count를 절대값이 아닌 **상대 비교·참고지표**로만 사용"하는 근거로 인용(Roboflow CC BY 4.0 데이터셋 출처 표기). 과제안내서의 "CCTV는 참고지표" 규정과 일치

### E. 아키텍처 4계층(Data Sources → AI Processing → Storage → UI) — 이미 우리 fig4와 동일 구조. 추가 반영 없음 (일치 확인용)

## 3. 쓸 수 없는 것 (배제) — 사유 명시

| BuildSmart 기능 | 배제 사유 |
|---|---|
| **XGBoost 지연 분류/회귀** (10,000 프로젝트) | ① 프로젝트 단위(도시·면적·총인력) 피처 ≠ 우리 일 단위 운영데이터 ② 우리 공정은 22개 → 지도학습 불가 ③ 합성 데이터로 학습된 모델을 가상 현장에 적용하면 "제공되지 않은 값을 사실처럼 생성" 위반 ④ 분류에 R² 사용 등 평가 오류 |
| **PPE 이미지 탐지 모델 자체** | 제공 사진은 AI 생성 참고용이며 정량분석 근거 금지(안내서 §6). 우리 과제는 "AI CCTV 설치한다" 식 기술 나열 지양 → 탐지 모델이 아니라 **탐지 결과(슬롯 집계)의 활용 규칙**이 과제 |
| **공급사 추천 / RL(DQN) 공급망** | 우리 데이터에 공급사·단가·리드타임 없음. DQN은 1-step(사실상 밴딧)에 컬럼명 불일치 버그 → 90일 파일럿 범위 밖 "초대형 시스템" |
| **도면(Blueprint) 탐지, 메트로 위험예측** | 과제 범위 외 |
| **Selenium 웹스크래핑 데이터 수집** | 현장 기밀·개인정보 수집 우려, 우리 입력은 기존 일보·허가서 사본으로 충분 |
| **범용 GPT 챗봇** | "대시보드·챗봇 구축" 식 기술명 나열에 해당. 질의응답보다 **의사결정 지점에 끼어드는 체크리스트**가 과제 취지 |

## 4. 반면교사 (우리 결과물에서 피할 점)

1. **모델 파일·경로 미포함 → 재현 불가**: 우리는 `analysis/*.py` 3개로 전 수치 재현 가능하게 유지 (평가기준 "분석가정·제외기준의 타당성")
2. **합성 데이터로 학습 후 실측처럼 보고**: 우리 "적용 후" 값은 모두 [가정] 표기 + 파일럿 실측 대체 명시
3. **AI 설명을 검수 없이 사용자에게 표시**: 우리 LLM 보조는 "안전팀 검수 후 배포" + 사람 최종 결정 명시
4. **8개 기능 나열형**: 우리는 1개 통합해결안(Pre-Clash Gate) + 3개 세부기능으로 집중 (미션 3 요건)
